The neural language model

Bengio's 2003 fix for the bigram's defects. Instead of a count table, each word becomes a learned vector \(C(w)\in\mathbb R^m\); the previous few vectors are concatenated, pushed through a \(\tanh\) hidden layer, and a softmax predicts the next word — the same head and cross-entropy loss as the bigram page. Train it live below and watch the embedding plane organize itself: words used in similar contexts drift together, which is exactly why it generalizes to sentences it never saw.

The embedding plane

Colours are our labels for reading the map — the model never sees them. It only ever sees which words precede which, yet nouns, verbs and places sort themselves into regions.

Training loss

Cross-entropy in nats; perplexity \(=e^{\text{loss}}\), the same metric as the bigram page. Minibatch SGD on the penalized log-likelihood.

Next-word distribution  ·  pick a context, read the model's prediction

Try the cat then a dog: once trained, the bars are nearly identical — the model learned the two nouns are interchangeable, so what it knows about one transfers to the other. That transfer is the whole point.

Generated sentences

— train the model, then generate —

This is still an order-\((n{-}1)\) Markov model — it sees a fixed window and nothing before it. What the neural form buys is not memory but generalization: parameters grow linearly in vocabulary and context (a count table grows as \(V^{\,n}\)), and the shared, smooth embedding gives structured backoff by similarity instead of the flat floor of add-\(\alpha\) smoothing. Set hidden units to \(0\) to recover the linear log-bilinear model; shrink the vocabulary and it collapses toward the bigram. The fixed window is the defect the recurrent network removes next.
