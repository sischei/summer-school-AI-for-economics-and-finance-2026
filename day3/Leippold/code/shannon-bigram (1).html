The bigram machine

Shannon's 1948 idea, at its simplest: a word-level Markov chain. It counts which word follows which, then random-walks those counts. Base estimator is plain maximum likelihood, P(next | current) = count(current, next) / count(current) — now with temperature and add-α smoothing layered on top.

Epistemic status: exact count estimator and exact sampling rule on a toy corpus. Generated prose is one controlled draw, not evidence about modern LLM quality.
Predict first. Hold the seed fixed. If you raise context order, temperature, or smoothing, which change should increase repetition, which should increase novelty, and which can remove dead ends?

Two knobs shape the walk. Temperature T resamples ∝ count1/T: toward 0 the walk becomes greedy and repetitive, while larger values flatten the successor distribution. Smoothing α adds a pseudo-count to every token in this corpus vocabulary, so any in-vocabulary token can follow any context and the chain no longer dead-ends.
